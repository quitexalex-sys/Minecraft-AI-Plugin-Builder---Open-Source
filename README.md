# Minecraft-AI-Plugin-Builder---Open-Source

# HOW TO INSTALL
1. Extract the zip.
2. Create the folder C:\MinecraftAI
3. Extract all the content in that folder
4. Open terminal as admin in the folder
5. Type in the terminal "python\python get-pip.py"
6. move the "maven" folder in C:\
7. Press WIN+R And type sysdm.cpl
8. Navigate to Advanced
9. Click on Enviornment Variables
10. Create a new Variable called PATH and in value type "C:/maven/bin"
11. Go to https://openrouter.ai/?ref=openrouter.com and click "Get API Key"
12. Create a new api key and copy it
13. In the terminal opened before "In C:\MinecraftAI" Run python\python app.py
14. Open a web broswer and type "localhost:12000"
15. Click on settings
16. Enter your api key and as model enter Custom and type "openrouter/free"
17. Done!
